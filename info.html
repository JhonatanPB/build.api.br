Sobre o BUILD

O BUILD é uma plataforma desenvolvida para auxiliar usuários na organização de tarefas, compromissos e anotações em um único ambiente. O sistema foi criado com foco em simplicidade, praticidade e produtividade.

A aplicação conta com páginas dedicadas para gerenciamento de notas, acompanhamento de tarefas e visualização de agenda, permitindo que o usuário mantenha suas atividades organizadas de forma rápida e intuitiva.

Este projeto foi desenvolvido utilizando HTML, CSS e JavaScript, demonstrando conceitos de interface web, responsividade, navegação entre páginas e manipulação básica de dados no navegador.

O objetivo principal do BUILD é oferecer uma experiência simples de organização pessoal, reunindo ferramentas essenciais em uma única plataforma moderna e de fácil utilização.
